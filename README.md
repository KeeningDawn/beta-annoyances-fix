# Beta Annoyances Fix

## Purpose

Playing on a Beta-mechanics server with a modern version client has some leftover annoyances that cannot be properly fixed without a mod. Some of these are hard to notice unless you're using other mods (e.g; ClientSort,) but they're annoying enough to warrant fixes anyway.

## Fixes

- Cookies stack to 8.
- All other food (Bread, Raw Fish, Cooked Fish, Raw Porkchop, Cooked Porkchop) stack to 1.
- Eggs stacks to 16.
- Miscellaneous items (Door, Sign) stack to 1.
